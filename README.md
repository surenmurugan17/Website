# Proportion Tech Website

Static HTML/CSS/JavaScript company website template.

## Local preview
Open `index.html` with VS Code Live Server.

## GitHub Pages
Repository can publish from `main` branch and `/ (root)`.

## Before launch
- Replace company name/logo.
- Replace placeholder email.
- Add real projects/case studies.
- Add approved company copy.
- Connect the contact form to a real form service/backend.
- Add final favicon and social preview image.
